# Deploying ACCURA INDUSTRIAL SUPPLIES to GitHub Pages

This project is configured for the GitHub repository name `accura-industrial-supplies` and will be published at:

`https://YOUR-GITHUB-USERNAME.github.io/accura-industrial-supplies/`

The site uses `HashRouter`, so pages have URLs such as `/#/products`. This is intentional: every route works reliably on GitHub Pages without server-side rewrite rules.

## 1. Create the repository

1. Sign in to GitHub and create a new public repository named **accura-industrial-supplies**.
2. Do not initialize it with another README, `.gitignore`, or license if this local project will be pushed directly.
3. From this project directory, initialize and publish the repository:

```bash
git init
git add .
git commit -m "Prepare website for GitHub Pages"
git branch -M main
git remote add origin https://github.com/YOUR-GITHUB-USERNAME/accura-industrial-supplies.git
git push -u origin main
```

If a remote named `origin` already exists, inspect it with `git remote -v` and update it with `git remote set-url origin URL` if necessary.

## 2. Enable GitHub Pages

1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, select **GitHub Actions** as the source. Do not select **Deploy from a branch**: that publishes the uncompiled source `index.html` and causes a blank React page.
4. Open the **Actions** tab and watch the **Deploy to GitHub Pages** workflow.
5. After it succeeds, use the deployment URL shown by the workflow or the Pages settings screen.

The workflow in `.github/workflows/deploy.yml` runs automatically after every push to `main`. It installs locked dependencies with `npm ci`, builds the website, uploads `dist`, and deploys it using GitHub's official Pages actions.

## 3. Publish future updates

After editing and testing locally:

```bash
npm install
npm run build
git add .
git commit -m "Update website"
git push
```

The push starts a new deployment automatically. GitHub Pages may take a few minutes to show the update.

## Repository name, username sites, and custom domains

The production base path in `vite.config.js` is `/accura-industrial-supplies/`, matching this project repository.

For a username site whose repository is exactly `YOUR-GITHUB-USERNAME.github.io`, or for a custom domain, change `base` in `vite.config.js` to `/` before building.

For a custom domain, add the domain in **Settings → Pages → Custom domain** and follow GitHub's DNS instructions. GitHub Pages hosting and HTTPS are free.

## Local verification

```bash
npm install
npm run build
npm run preview
```

The generated production files are in `dist`. Do not edit `dist` manually; it is regenerated by the build.
